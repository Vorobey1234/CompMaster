# КомпМастер — сайт сервисного центра по ремонту компьютеров

Учебный проект: многостраничный сайт на HTML, CSS и JavaScript.
Стек: Flexbox и Grid, CSS-переменные, БЭМ, Bootstrap 5 (CDN), Bootstrap Icons.

## Просмотр проекта

Откройте GitHub Pages по ссылке ниже. Для локального просмотра скачайте или клонируйте репозиторий и откройте `index.html` в браузере.

```bash
git clone https://github.com/Vorobey1234/CompMaster.git
```

## Страницы

- `index.html` — главная: баннер с записью на диагностику, о сервисе, преимущества, популярные услуги, этапы работы, статистика.
- `catalog.html` — каталог: 12 услуг, боковая панель с фильтрами по категории и стоимости, кнопка «Подробнее» открывает модальное окно.
- `service.html?id=N` — страница услуги (цена, срок, состав, этапы) и форма заявки на ремонт.
- `reviews.html` — отзывы клиентов сервисного центра.
- `contacts.html` — адрес, режим работы, карта, форма обратной связи, FAQ.

## Где что реализовано

| Требование | Реализация |
|---|---|
| Единое меню и подвал | `site-header` / `site-footer` на всех страницах |
| Закреплённое меню | `position: sticky` (`.site-header`) |
| Хлебные крошки | блок `.breadcrumbs` на внутренних страницах |
| Якорные ссылки | пункты меню `#advantages`, `#steps`, `#faq` |
| Модальное окно услуги | Bootstrap Modal `#service-modal`, кнопки `data-service` |
| Фильтры каталога | `js/main.js`: `filters-form`, счётчик «показано … из 12» |
| Метки на карточках | «Популярное», «Скидка», «Быстрое обслуживание» (`.badge-tag`) |
| Проверка форм | `data-validate`, `checkValidity()`, подсветка `aria-invalid`, сообщения об успехе/ошибке |
| FAQ | Bootstrap Accordion на странице «Контакты» |
| Кнопка «Наверх» | `#scroll-top` (появляется после 500px прокрутки) |
| БЭМ / CSS-переменные / Flex+Grid | `css/style.css` |

## Данные услуг

Все 12 услуг описаны в массиве `SERVICES` в начале `js/main.js`:
из него отрисовываются карточки каталога, популярные услуги на главной,
содержимое модального окна и самой страницы `service.html`.
